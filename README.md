#  THR10II + Rocksmith Replication Guide (beginner-friendly, follow in order, ~15 minutes)

> This guide only tells you **what to do**, not why. The whole process is **4 steps**:
> **① Restore the 32-bit driver component → ② Put 3 files into the game folder → ③ Edit two .ini files → ④ Launch and verify**
>
> If you meet an unfamiliar word, jump to the [Glossary](#glossary) at the bottom and come back.

## Step 0: What you need (all free)

| Need | From | Used for |
|---|---|---|
| Old Yamaha driver package `Yamaha Driver THRII v1.0.0.0` | Yamaha's website (or let the included script download it automatically) | We only take 2 small files out of it — we do **not** install it |
| 7-Zip | [7-zip.org](https://www.7-zip.org) | To open (unpack) the old package and take the files |
| RS ASIO package `release-0.7.5.zip` | rs_asio official GitHub Releases page | Its 3 files go into the game folder |

> If the 64-bit Yamaha driver (v2.0.0.0) is already installed, leave it alone —
> **your job is not to reinstall a driver, it's to "add one missing file".**

## Step 1: Restore the 32-bit driver component (once; requires Administrator)

**What this step does**: Rocksmith is a 32-bit program and needs a 32-bit audio driver
component. The new Yamaha driver does not ship one; the old one does. We only "borrow"
that component from the old package and put it into the system — **without installing
the old driver itself**.

**Pick one of the two:**

### Option A: One-click script (recommended)

1. Download `restore_32bit_asio.cmd`
2. **Right-click → Run as administrator**
3. It automatically: downloads the old package → unpacks it → drops the 2 files into
   `C:\Windows\SysWOW64` → writes the registry
4. At the end you should see three lines of `[OK]` (if you see `[FAIL]`, screenshot it and ask)

### Option B: Manual (use this if you want to see every piece)

1. Open the old package with 7-Zip (right-click → 7-Zip → Open archive)
2. Go to `Driver Archive\THRII\` and **extract** these two files:
   - `YamahaTHRIIAsio_OnInterposer.dll`
   - `InterposerTHRIIBackend.dll`
3. Open "This PC" → `C:\Windows\SysWOW64` (**SysWOW64 — not System32**)
   - Tip: paste `C:\Windows\SysWOW64` into the address bar and press Enter
4. **Copy & paste** both files in there (an admin confirmation prompt may appear — click Yes)
5. Double-click `restore_32bit_asio.reg` to import the registry patch, click Yes on all prompts

**✅ How to verify**: open `C:\Windows\SysWOW64` in File Explorer and you can see both
files (names match).

## Step 2: Put 3 files into the game folder (no admin needed)

**Where is the game folder**: Steam Library → right-click Rocksmith → Manage → Browse local files
(usually: `C:\Program Files (x86)\Steam\steamapps\common\Rocksmith2014`)

Open `release-0.7.5.zip` and **copy all 3 files** into the game folder:

| File | What it is |
|---|---|
| `RS_ASIO.dll` | The core (the game loads it automatically at startup) |
| `avrt.dll` | Companion helper |
| `RS_ASIO.ini` | Config file (this is what we edit in the next step) |

> ⚠️ Do **not** touch, move or delete any DLC or game files — we're only *adding* files.

**✅ How to verify**: you can see these 3 new files in the game folder.

## Step 3: Edit two config files (plain Notepad is fine)

### 3.1 Edit `RS_ASIO.ini` (the one in the game folder)

Open it in **Notepad** → Select All → Delete → paste the content below → Save (Ctrl+S).

```ini
[Config]
EnableWasapiOutputs=0
EnableWasapiInputs=0
EnableAsio=1

[Asio]
BufferSizeMode=custom
CustomBufferSize=128

[Asio.Output]
Driver=ASIO THRII
BaseChannel=0
AltBaseChannel=
EnableSoftwareEndpointVolumeControl=1
EnableSoftwareMasterVolumeControl=1
SoftwareMasterVolumePercent=100
EnableRefCountHack=

[Asio.Input.0]
Driver=
Channel=0
EnableSoftwareEndpointVolumeControl=1
EnableSoftwareMasterVolumeControl=1
SoftwareMasterVolumePercent=100
EnableRefCountHack=

[Asio.Input.1]
Driver=ASIO THRII
Channel=1
EnableSoftwareEndpointVolumeControl=1
EnableSoftwareMasterVolumeControl=1
SoftwareMasterVolumePercent=200
EnableRefCountHack=

[Asio.Input.Mic]
Driver=ASIO THRII
Channel=1
EnableSoftwareEndpointVolumeControl=1
EnableSoftwareMasterVolumeControl=1
SoftwareMasterVolumePercent=200
EnableRefCountHack=
```

> The 4 lines worth understanding:
> - `Driver=ASIO THRII` → use the THR10II's own ASIO driver (restored in Step 1)
> - `Channel=1` (input) → take only the **right channel** — the right channel is the
>   **dry signal** (unprocessed guitar, which the game needs for pitch detection)
> - `SoftwareMasterVolumePercent=200` → the dry signal is quiet, so boost it to 200%
> - `CustomBufferSize=128` → audio buffer (smaller = less latency but more crackling; this is the sweet spot)

### 3.2 Check `Rocksmith.ini` (in the game folder, generated by the game)

Open it in Notepad, find the `[Audio]` section and make sure these 2 lines **must be**:

```ini
ExclusiveMode=1
Win32UltraLowLatencyMode=1
```

If they aren't 1, change them to 1 and save.
(`LatencyBuffer=1` is also recommended; tuning tips are in the FAQ below.)

**✅ How to verify**: reopen both files in Notepad and confirm the content matches what
you pasted/changed.

## Step 4: Launch and verify (3 checkpoints)

**⚠️ Important: do not run Voicemeeter** (if you have it installed, fully exit it).

1. Launch the game from Steam → **no error popup** (an "exclusivity" error = Step 3.2 wasn't done right)
2. Main menu → **you can hear the background music** (if not: check the amp's SOURCE
   switch is on USB, and turn the volume up)
3. Tuner screen → pick a string → **the string indicator settles stably on the pitch**
   (no wild jumping = input is working)

**✅ Ultimate check (the log)**: after quitting the game, open `RS_ASIO-log.txt` in the
game folder with Notepad and look for:
- `Creating AsioSharedHost - dll: ...\SysWow64\YamahaTHRIIAsio_OnInterposer.dll` = the
  32-bit component is active ✔
- **No** `Failed to create ASIO buffers` = everything is fine ✔

## Quick FAQ (check this first when something's wrong)

| Symptom | First thing to do |
|---|---|
| Popup about "exclusivity" | Is `ExclusiveMode` in `Rocksmith.ini` back to 0? (the game can rewrite it) |
| Tuner jumps around, unrelated to what you play | 99% Step 1 wasn't done right → rerun the script and check for `[OK]`; make sure Voicemeeter is closed |
| Sound but crackling (pops) | First **turn down the amp's master / guitar volume / gain knobs** (don't overthink which one); if it still crackles, raise `CustomBufferSize` 128→192→256 |
| Feels like it lags behind | 128 is already the sweet spot; if it still feels dull, try 96 (if it starts crackling, don't use it) |
| Note highway doesn't line up with the music | Use the in-game "visual latency calibration" (the screen that says picture is slower than sound): tap along with what you **hear**, repeat a few times |
| "Device in use" error (0xC00D4E85) | Another program is holding the sound card exclusively — close it, then restart the game |
| The game keeps rewriting the ini | After fixing it, mark `Rocksmith.ini` as read-only (right-click → Properties → tick Read-only) |

**Config changes only take effect after restarting the game.**

## Glossary (5 words — enough)

| Word | One-line explanation |
|---|---|
| ASIO | A professional audio interface with low latency. The game normally doesn't use it; RS ASIO makes it |
| 32-bit / 64-bit | The program's "caliber" — Rocksmith is 32-bit and can only load 32-bit driver components (this is why Step 1 exists) |
| Dry / Wet | Dry = raw guitar signal (what the game needs); Wet = signal with amp modeling/effects (the game can't use it) |
| SysWOW64 | Where 32-bit programs load their components on 64-bit Windows (home of the Step 1 DLLs) |
| ini | A plain-text config file, editable with Notepad |
